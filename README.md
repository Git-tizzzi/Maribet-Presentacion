# Maribet-Presentacion
Pagina web de presentacion de emprendimiento para "Maribet"
La funcion de esta pagina web es dar una breve presentacion al usuario de que es "Maribet", cuando fue creado el
emprendimiento y con informacion de contacto para comunicarse ante cualquier duda con el soporte de la pagina.
*Desarrollado con React Native
*Link directo a la pagina web para realizar compras
