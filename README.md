# Maribet

Landing page de presentación hecha con React + Vite.

## Ejecutar
    npm install
    npm run dev      # desarrollo
    npm run build    # versión final en /dist

## Configurar (src/config/siteConfig.js)
- `STORE_URL`: URL de la tienda online (el botón "Maribet" la usa).
- `HERO_IMAGE`: ruta de la foto, ej. `/images/boutique.jpg` (guardala en `public/images/`).
